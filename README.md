# Sistema de Gerenciamento de Animais Resgatados

Projeto desenvolvido para a disciplina de Atividade Extensionista do curso de Análise e Desenvolvimento de Sistemas.

O sistema tem como objetivo facilitar o cadastro e a organização das informações de animais resgatados.

## Funcionalidades

- Cadastro de animais
- Edição e exclusão de cadastros
- Busca de animais
- Registro de informações do resgate
- Histórico veterinário
- Controle de vacinação e castração
- Situação de adoção
- Área de animais disponíveis para adoção
- Registro de informações do adotante

## Tecnologias utilizadas

- Python
- Flask
- HTML
- CSS
- SQLite
